# accordion

<ThemeToggle />

<Basic shows="Three questions. Opening one closes the last." />

Questions on a help page, the parts of a long form: an accordion shows one section at a time and
keeps the rest folded away. Each section is named by its own `value`, so the root's `value` is
simply the name of the one showing, and reordering sections changes nothing.

## Props

- `value` on the root names the section showing. Omit it and everything starts closed.
- `multiple` lets sections open on their own, and `value` becomes the list of names.
- `collapsible={false}` stops the open section being closed, so one always shows.
- `value` on an item is that section's name. It is the one required prop.
- `disabled` locks a single item, or the whole accordion from the root.

## Keyboard

Focus lives on the triggers, and the walk steps over any trigger that is disabled.

| Key | What it does |
| --- | --- |
| Down arrow | Focus the next trigger, wrapping round to the first. |
| Up arrow | Focus the previous trigger, wrapping round to the last. |
| Home | Focus the first trigger. |
| End | Focus the last trigger. |
| Enter or Space | Open or close the focused section. |

## Managing which section is open

`onChange` hands you the new value each time a person opens or closes a section.

<Value shows="The value names the second section, so the second one is open." />

```tsrx
<accordion.root value="returns" onChange={(next) => console.log(next)}>
```

## Several open at once

<Multiple shows="Two panels open together. Opening the third leaves both alone." />

```tsrx
<accordion.root multiple value={['ship', 'returns']}>
```

## Always one open

<Locked shows="Press the open trigger and it stays open. Only the other one closes it." />

```tsrx
<accordion.root value="ship" collapsible={false}>
```

## A section that will not open

The trigger is disabled natively, so nothing has to remember to skip it.

<Disabled shows="The middle trigger is dead. Arrow keys jump straight past it." />

```tsrx
<accordion.item value="trade" disabled>
```

## Find in page

A closed panel is `hidden="until-found"`, so a browser search opens the section it lands in. A
disabled section's panel is hidden outright, and `disableUntilFound` does that to every closed
panel.

<Find shows="Search the page for Antarctica. The closed section opens on the match." />

```tsrx
<accordion.root disableUntilFound>
```

## API reference

Every prop is optional unless its row says otherwise. State arrives as `ui-*` attributes, which
[styling](/markless/ui/styling) explains once for every family.

### `accordion.root`

| Prop | Type | What it does |
| --- | --- | --- |
| `value` | `string \| readonly string[]` | Which section is showing. With `multiple` it is the list of sections showing. Omit it and everything starts closed. |
| `multiple` | `boolean` | Several sections may show at once. Without it, opening one closes the rest. |
| `collapsible` | `boolean` | Whether the section showing may be closed again, leaving nothing open. On by default. |
| `disabled` | `boolean` | Nothing opens or closes while this is set. |
| `disableUntilFound` | `boolean` | Closed panels are hidden outright, so find-in-page cannot reach the text inside them. |
| `onChange` | `(value: string \| readonly string[]) => void` | Called with the new value when a person opens or closes a section. |

Renders a `<div>`, which everything but `onChange` passes through to. Writes `ui-multiple` and
`ui-disabled`.

### `accordion.item`

| Prop | Type | What it does |
| --- | --- | --- |
| **`value`** | `string` | Required. This section's own name, and what the root's `value` matches against. |
| `disabled` | `boolean` | This one section opens and closes for nobody. |

Renders a `<div>`, which everything else passes through to. Writes `ui-value`, `ui-open`,
`ui-closed` and `ui-disabled`.

### `accordion.itemlabel`

The heading naming the panel. No props of its own; renders an `<h3>`, and `accordion.itemcontent`
points its `aria-labelledby` here.

### `accordion.itemtrigger`

The button that opens and closes the section. No props of its own; renders a `<button>`, and your
own `onClick` runs after the section has opened or closed. Writes `ui-open`, `ui-closed`,
`aria-expanded`, `aria-controls`, and the native `disabled`.

### `accordion.itemcontent`

The panel. No props of its own; renders a `<div>` with `role="region"`, and your own
`onBeforematch` runs after find-in-page has opened the section. Writes `ui-open`, `ui-closed`,
`aria-labelledby` and `hidden`.
